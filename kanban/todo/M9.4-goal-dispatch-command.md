# M9.4 · `/goal-dispatch` command

**Status:** todo
**Goal:** M9
**Size:** medium

## What

New slash command (with supporting script in `tools/`) that takes a goal ID, refuses to spawn when the goal's `Paths:` overlap an in-flight goal, creates the per-goal branch and worktree, and kicks off an agent session against the goal. This is the runtime enforcement counterpart to M9.2's definition-time surfacing.

## Scope

- `/goal-dispatch <goal-id>` lives in `.claude/commands/`
- Supporting script in `tools/` (shape decided at implementation time)
- Reads `**Paths:**` from the target goal and from all in-flight goals; refuses to proceed on overlap with a clear message naming the conflicting goal
- Creates the goal branch from `main` if absent; creates the worktree
- Spawns an agent against the goal

## Dependencies

M9.1 (needs `Paths:` field). Soft dependency on M9.3 (per-goal branch convention defined) — implementable without it but the branch name lives in the same convention space.

## Verification

`/goal-dispatch <id>` on a non-overlapping goal creates the per-goal branch and worktree and starts an agent. On an overlapping goal, the command refuses and names the conflicting goal.
