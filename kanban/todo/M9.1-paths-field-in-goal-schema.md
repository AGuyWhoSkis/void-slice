# M9.1 · `Paths:` field in goal schema

**Status:** todo
**Goal:** M9
**Size:** small

## What

Add a machine-readable `**Paths:**` field to the goal file format so downstream tooling (overlap surfacing in `/goal-define`, refusal in `/goal-dispatch`) can compare goals' surfaces without parsing prose. Pure schema + docs ticket — no behavior change. M9 is the only currently active goal that needs to declare `Paths:`; closed goals (M1–M8) stay bare since overlap checking only matters for in-flight goals.

## Scope

- **Format.** `**Paths:**` field placed between `**Scope:**` and `**Status:**` in the goal file. Bullet list, one path per line:

  ```markdown
  **Paths:**
  - internal/scan/**
  - internal/parse/**
  ```

- **Glob syntax.** Doublestar globs (`**`, `*`, `?`), repo-relative, no leading slash. The schema doc says "matches the same conventions as Go tooling (`golangci-lint`, etc.)." Library choice for evaluation is deferred to M9.4 (the dispatcher is what evaluates).

- **Overlap definition.** Two `Paths:` fields overlap iff some concrete file in the working tree matches a pattern in both — set-intersection of matched paths. Documented as the contract; no other definition is correct (pattern-prefix or directory-share rules produce false positives).

- **Cross-cutting files always declared.** No implicit allowlist for files like `go.mod`, `Makefile`, `CLAUDE.md`, `kanban/README.md`. If two goals both edit `Makefile`, they conflict and serialize. Schema doc names this rule explicitly.

- **Schema documentation lives in `kanban/README.md`** as a new subsection in the Goals section. Terse — same tone as the rest of README. Covers: format, glob syntax, overlap definition, cross-cutting rule, and that closed goals don't need to declare.

- **M9's own `Paths:` declaration** added to `kanban/goals/M9.md`:

  ```markdown
  **Paths:**
  - .claude/commands/**
  - .claude/plans/**
  - .github/**
  - kanban/README.md
  - kanban/goals/M9.md
  - kanban/todo/M9.*
  - tools/**
  - CLAUDE.md
  ```

- **Closed goals untouched.** M1–M8 do not get a `Paths:` field.
