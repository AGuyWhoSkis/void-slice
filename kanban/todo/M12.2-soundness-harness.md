# M12.2 · Soundness harness (property-based locality fuzzing)

**Status:** todo
**Goal:** M12
**Size:** large
**Origin:** M12.1

## What

Build the property-based locality harness inside `internal/` per §3 of [`kanban/goals/M12-cascade-investigation.md`](../goals/M12-cascade-investigation.md). For each clean golden under [`testdata/golden/`](../../testdata/golden/), apply a single byte-level mutation at a known span and assert that all new diagnostics (post-baseline) fall within a small line window of the mutated span. Shapes covered: unterminated-quote, unterminated-block-comment, unterminated-brace (the three §2 confirmed cascade). Missing-semicolon stays a regression case (no cascade expected — fail closed if it ever starts cascading).

The harness becomes the rolling soundness check that the M12 goal anchors to. It hangs off `make harnesses` and gates CI alongside `go test ./...` and the existing per-layer harnesses (M8.1–M8.4). The throwaway harness used in M12.1 lives under `/tmp/` and is not the deliverable — it pinned the technique but is not the long-term form.

## Scope

- **New package:** `internal/harness/locality/` (or fold into `internal/lint/` if smaller). Pure Go, no external deps beyond `testify`.
- **Mutator set:** one mutator per cascading shape from §2 of the memo — `mutateUnterminatedQuote`, `mutateUnterminatedBlockComment`, `mutateUnterminatedBrace`. Plus `mutateMissingSemicolon` as a negative case (must produce **no** outside-line diagnostics — fails the test if it ever cascades).
- **Locality property:** given baseline diagnostics on a clean file `f` and post-mutation diagnostics on `mut(f, span)`, the set `post - baseline` (matched on `(line, col, code)` to subtract clean-file noise like `LINT_VE_INCONSISTENCY`) must have every diagnostic land in a line window of ±W around the mutated span. Start with W=1 (the M12.1 brace cascade is off-by-one at W=0); if W>1 hides real cascades on the corpus, narrow it back to 0 and accept the brace as a known-pending fix.
- **Driver:** Go `testing.T`-based, walking the same corpus the existing clean-sweep tests walk (`testdata/golden/`'s flat root + `d2/game1/` + `doto/game1/`). For each (file, shape) pair, run mutator → lint → assert. Skip files where the mutator cannot apply (e.g. `missing-semicolon` on a file without `;`).
- **`make` target:** wire as a new sub-target under `make harnesses` (or extend the existing harness driver). The harness must currently fail — every cascading shape from §2 violates the property — so it lands **paired with the fixes in M12.3/4/5**, or as a known-failing harness gated off CI until M12.3/4/5 land. Coordinate with the implementer on whether to merge M12.2 as known-failing or hold M12.2 until at least one fix ticket lands.

## Dependencies

M12.1 (closed when this is filed). M12.3/4/5 are siblings — they need this harness to verify their fixes; this harness needs them to actually pass on CI.

## Verification

- `make harnesses` runs the new locality harness as a new sub-target.
- Locality harness exercises ≥3 mutator shapes against ≥1 sample per format-game cell (`.entities` × {D2, DOTO}, `.decl` × {D2, DOTO}) plus the committed [`testdata/cascades/`](../../testdata/cascades/) fixtures (regression cases).
- On a known-cascading scanner state (baseline), the harness reports specific (file, shape, outside-line-codes) tuples — diagnostic enough for a fix-ticket implementer to root-cause without re-running the M12.1 throwaway script.
- Missing-semicolon stays the negative case: if the mutator applies and the parser regresses to a cascade, the harness fails.
- `go test ./...` and `go vet ./...` clean.

## Out of scope (intentionally deferred)

- Fixing any cascade — M12.3 / M12.4 / M12.5 own per-shape fixes.
- Cross-corpus differential (D2 vs DOTO vs Deathloop) — deferred per M12.md.
- Completeness oracles (idParser differential, Void Engine round-trips) — future goal.
- Choice of fuzzing library beyond Go stdlib (`testing.F` may layer under property tests later for crash/hang coverage; not required for M12.2's first cut).
