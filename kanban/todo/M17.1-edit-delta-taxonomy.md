# M17.1 · Edit→delta surprise taxonomy

**Status:** todo
**Goal:** M17
**Size:** medium

## What

Investigation-only ticket. Map the edit→diagnostic-delta surprise space across the lint engine and produce a draft taxonomy of surprise classes — i.e. cases where the delta between `voidslice lint <file>` before and after an edit does not match the apparent scope of the edit. Cover both (a) edits that should change nothing but do (M13's invariance frame, extended past inter-token whitespace), and (b) edits whose delta is disproportionate to their span (M12's cascade frame, generalized past unterminated-token shapes).

Deliverable is a memo at [`kanban/goals/M17-edit-delta-taxonomy.md`](../goals/M17-edit-delta-taxonomy.md), modeled on M12.1's [`M12-cascade-investigation.md`](../goals/M12-cascade-investigation.md) and M11's `M11-idtech-reach.md`. No engine code modified — `internal/scan/`, `internal/parse/`, `internal/validate/`, `internal/lint/`, `internal/report/`, `worker/`, `cmd/voidslice-wasm/` stay clean for M17.2's root-cause work and the phase-3 fix tickets sliced after M17.2.

Probing approach: extend the existing lexinvariance scaffolding in [`internal/harness/lexinvariance/`](../../internal/harness/lexinvariance/) for whitespace-shaped transforms; for novel edit classes (single-char punctuation flips, identifier renames, line splits/joins, comment toggles, …) use throwaway scripts kept under [`testdata/`](../../testdata/) or inline in the memo. The point is breadth of probing, not harness design — phase 2 (M17.2) decides what becomes durable infrastructure.

- **Edit-class families to probe** (minimum set; expand if §2 surfaces gaps):

  | Family | Example transform | Substrate |
  |---|---|---|
  | Inter-token whitespace | already covered by [`internal/harness/lexinvariance/`](../../internal/harness/lexinvariance/) hard gate | re-confirm zero, no new probing needed |
  | Blank-line / newline mutation | `TransformBlankLine` + reindent newline-injection paths | extend lexinvariance (triage-only today) |
  | Single-char punctuation flip | `{` → `(`, `;` → `,`, `"` → `'` at a known span | ad-hoc script |
  | Line split / join | insert / remove `\n` mid-line at non-token boundaries | ad-hoc script |
  | Comment toggle | wrap / unwrap a line with `//` or `/* */` | ad-hoc script |
  | Identifier rename | rename a referenced identifier consistently across one file | ad-hoc script |
  | Single-char append / delete | append / delete one byte at random spans (smoke) | ad-hoc script |

- **Throwaway scripts** live under [`testdata/m17-probes/`](../../testdata/) (new dir) as Go test files, shell scripts, or fixtures — whichever is cheapest per probe. They are not wired into `go test ./...` and not exported to other packages. The memo's §4 lists what was committed and how to re-run each probe.
