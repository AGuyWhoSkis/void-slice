# M9.5 · Branch protection as code

**Status:** todo
**Goal:** M9
**Size:** small

## What

Move the merge guardrail for `main` out of the GitHub UI into committed `.github/` config (ruleset, CODEOWNERS, or whichever shape fits). Merge to `main` requires human approval and green required CI checks; enforcement lives in the repo so it survives UI drift and applies to agents and humans uniformly. This is the trust anchor that makes the rest of M9 safe to operate.

## Scope

- `.github/` config (ruleset or equivalent) committed and active on `main`
- Required: at least one human approval, green required checks (`go test`, harnesses, lint)
- Enforcement is mechanical — an agent attempting to self-merge cannot succeed regardless of prose instructions
- No prose-as-policy in `CLAUDE.md` substitutes for the protection (informational mention is fine; enforcement claims are not)

## Dependencies

None.

## Verification

A test PR cannot be merged into `main` without an approving review and green required checks. `.github/` contains the durable config that produces this behavior.
