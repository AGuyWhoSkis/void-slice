# M13.2 · Document the lexinvariance gate contract in CLAUDE.md

**Status:** todo
**Goal:** M13
**Size:** small

## What

Document the new lexinvariance hard gate landed in M13.1. The goal's
load-bearing constraint — closures by engine fix or input-boundary router
only, **never** by per-file skip list — must be written down where future
contributors and agents will find it on first read, not buried in commit
history. The forcing reason (the web playground accepts pasted text without
a filename, so path-based skips can't apply to the surface that serves
users) needs to be in the doc so the rule is reasoned, not arbitrary.

## Scope

- `CLAUDE.md` — extend the **Tooling > Harnesses** section. Add a paragraph
  (or sub-bullet) covering:

  1. **What the gate is.** `TestLexinvarianceHardGate` runs under
     `go test ./...` and walks `testdata/golden/`. Fails on any finding
     whose `TransformKind.IsHardGate()` returns true (Reindent, TabSpace,
     InterTokenPadding). BlankLineJitter findings remain triage-only via
     `make lexinvariance`.
  2. **The two allowed closure mechanisms.** Either (a) fix the engine
     (scan / parse / validate) — the M12.16/17 precedent of unwinding a
     cascade caused by indent- or close-gating — or (b) route the file's
     class to a no-op handler at the linter's input boundary
     (`internal/lint/lint.go`'s `classifyFile`/action enum) — the M12.18
     precedent of routing HLSL-prefix `.decl` files.
  3. **No per-file skip list.** State the prohibition and the forcing
     reason: the web playground accepts pasted text without a filename, so
     a path-based skip would silently lie about coverage on the surface
     that serves users.

  Code/file references in the doc should use the [text](path) link form
  the repo's CLAUDE.md already uses elsewhere.

## Format example

Suggested insertion under **Tooling > Harnesses** (exact prose at the
implementer's discretion, but covering all three points above and
preserving the existing list style):

```markdown
- **Lexinvariance gate:** `TestLexinvarianceHardGate` in
  [`internal/harness/lexinvariance/`](internal/harness/lexinvariance/) runs
  under `go test ./...` and fails on any finding from a hard-gate transform
  (Reindent, TabSpace, InterTokenPadding) across `testdata/golden/`. New
  findings close by **either** an engine fix (M12.16/17 precedent) **or** an
  input-boundary router in
  [`internal/lint/lint.go`](internal/lint/lint.go)'s `classifyFile`
  (M12.18's `actionShaderDecl` precedent) — **never** a per-file skip
  list. The playground accepts pasted text without a filename, so a
  path-based skip would silently lie about coverage on the surface that
  serves users. BlankLineJitter findings stay triage-only via
  `make lexinvariance`.
```
