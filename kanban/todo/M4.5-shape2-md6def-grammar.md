**Status:** todo

## What

Shapes 2 (animset) and 5 (md6def) share a near-identical lex profile per the taxonomy doc: curly-braced root, **no** `=`, **no** `;`, whitespace-separated key-value pairs with quoted-string values, integer literals, and nested object blocks. Together they account for 7 + 1 = 8 files but **628,623 + 22 = 628,645 PARSE_UNEXPECTED_TOKEN hits** — the largest single drain in the corpus. The taxonomy doc's explicit guidance is to fold both into one walker rather than carve them separately.

This is the **parser-layer Shape-2/5 golden coverage** ticket.

## Scope

- New parser walker covering whitespace-separated, no-`=`/no-`;` curly-braced grammar with: top-level key-value pairs (`previewmd6 "…"`, `skeleton "…"`), nested blocks (`groups { … }`, `aliases { … }`, `init { … }`), positional integers (`group 0`, `lod 0`), and quoted string values.
- Walker fronts both Shape 2 and Shape 5 dispatch routes (already wired by M4.3's content-sniff: `previewmd6` → Shape 2; `init` → Shape 5).
- Emit `OnAssignment` / `OnTypedBlock` / `OnObjectBegin/End` events analogous to the Shape-1 walker so downstream validators see a uniform shape.

## Dependencies

M4.3 (dispatch).
