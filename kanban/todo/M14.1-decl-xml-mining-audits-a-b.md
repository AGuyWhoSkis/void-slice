# M14.1 · `.decl.xml` mining + audits A & B

**Status:** todo
**Goal:** M14
**Size:** medium

## What

Investigation-only ticket. Mine the 12 `.decl.xml` `<ResourceInfo>` records in [`testdata/golden/`](../../testdata/golden/) into a single in-memory table of `(filename, declared-name, classname)`, then run two measurements against it:

- **Audit A** — filename ↔ declared-name round-trip rate. Define a forward transform `filename → expected-name` (e.g. strip `generated.decls.` prefix, strip `.decl.xml` suffix, drop class-bucket prefix segments, replace `.` with `/`). Apply to each of the 12 filenames; count exact matches against `<ResourceInfo>` `name`. Report the rate, the failure shapes, and how predictable any unmatched cases are.
- **Audit B** — inherit-graph resolution rate per kind. Walk every `inheritedDecl = "..."` and top-level `inherit = "..."` string across [`testdata/golden/`](../../testdata/golden/) `.decl` and `.entities` files. For each, attempt resolution against the 12-record table (the only declared-name source available intra-workspace). Bucket by *kind* = the dot-segment suffix after the last `.` of the cited target (e.g. `.cpnthealthevolved`, `.def`, no-suffix). Report per-kind resolution rate plus the **suffix-tolerance list** — the concrete transformations any future resolver would have to encode (case-folding, `.def` optional, `..` filename-grammar, class-prefix stripping, etc.).

Methodology mirrors [M12.1](../../kanban/goals/M12-cascade-investigation.md)'s throwaway-harness approach: the audit code lives at `/tmp/m14-audit/` (not committed). The committed deliverable is the report file plus minimal-repro fixtures only where they sharpen a finding.

Lands the report file at `kanban/goals/M14-declared-typing-investigation.md` with the H2 scaffold below and **§1** and **§2** filled. The TL;DR, methodology footnote, gameN-gap statement, next-goal proposal, and **§3** are explicitly left as stubs — they are M14.2 and M14.3's contracts.

No code under `internal/` is touched.
