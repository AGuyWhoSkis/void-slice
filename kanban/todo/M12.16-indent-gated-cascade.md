# M12.16 · Indent-gated cascade in unterminated-quote recovery

**Status:** todo
**Goal:** M12
**Size:** medium
**Origin:** M12.15 — F3/F4 in `lexinvariance-report.md`

## What

The M12.15 lexinvariance harness surfaced the V1/V2 cascade the spike
was chartered to find. `testdata/cascades/lexinvariance/whitespace-cascade.decl`
lints to 7 diagnostics in its committed form:

```
PARSE_UNEXPECTED_TOKEN ×3
PARSE_UNTERMINATED_OBJECT ×3
VOID_SCAN unterminated quote
```

Apply `TransformReindent` variant 1 (strip leading whitespace) or
`TransformInterTokenPadding` variant 0 (collapse inter-token gaps) and
the same logical file lints to:

```
VOID_SCAN unterminated quote
```

The 6-diag PARSE cascade is gated entirely by leading whitespace on the
line containing the recovery-anchor `}`. Same logical input, lexical
token stream unchanged, diagnostic-code multiset diverges by 6.

This is the M12 axiom violated on a new axis: M12.12 routed EOF anchors
by "block-closer vs inline" — turns out the routing is *also* sensitive
to indent depth. The fix path here lives in the parser's recovery
heuristic, not in the lexinvariance harness itself.

## Scope

- Find the path in `internal/parse/` where the `}` recovery anchor is
  selected. Bisect locally: lint both V1 and V2 (the variant bytes
  produced by `TransformReindent` variant 1), trace which branch fires
  differently.
- Make the heuristic indent-invariant: a column-0 `}` and an indented
  `}` should produce the same recovery shape.
- Pin the V1/V2 case with a fixture-level test under
  [`internal/parse/`](../../internal/parse/) or
  [`internal/lint/`](../../internal/lint/) that lints both versions of
  the cascade fixture and asserts equal diagnostic-code multisets.
- Re-run `make lexinvariance` — F3 and F4 should disappear from the
  report. F5/F6 (M12.17's shape) and F1/F2 (M12.18's shape) are
  expected to persist; this ticket fixes one shape only.

### Out of scope

- Fixing F1/F2 or F5/F6. Each is its own ticket.
- Removing `testdata/cascades/lexinvariance/whitespace-cascade.decl` —
  the fixture stays so the regression test pins the fix.

## Dependencies

- M12.15 (the harness must land first so the regression test has
  somewhere to anchor).
