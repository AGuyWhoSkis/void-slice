# M10.4 · `/goal-slice` adoption + atomic-claim push

**Status:** todo
**Goal:** M10
**Size:** medium

## What
Add nit adoption to `/goal-slice`. After the slicer drafts the goal's intentional tickets, surface fitting pending nits, ask the user which to adopt, atomically claim each via `git push` to the `nits` branch, and materialize each successfully claimed nit as a ticket on the goal branch with `**Origin:** nit-<timestamp>`.

## Scope
- Edit `.claude/commands/goal-slice.md`:
  - Add a new step `### Adopt nits` between current step 3 (Write the files) and step 4 (Hand off). Adoption runs *after* the slicer's intentional tickets are written so the goal's own seams are settled first.
  - Step does:
    1. `git fetch origin nits 2>/dev/null`. If branch absent, print `(no nits substrate)` and continue.
    2. List pending nits in the same table format as M10.3, marking fits-this-goal (Paths-subset check).
    3. Prompt: `Adopt fitting nits? (all / none / pick subset)`.
    4. For each adopted nit, call `tools/nit-claim.sh <goal-id> <nit-filename>`. Script returns 0 on win, 2 on race, 3 on network failure.
    5. On win (0): write a ticket at `kanban/todo/<goal-id>.<n>-<slug>.md` (n = next free per `/crud-ticket` rules) using the materialized format below.
    6. On race (2): print `<file> already claimed by another goal; skipping`.
    7. On network failure (3): surface and stop the adoption step; partial claims are fine, manual retry possible.
- New `tools/nit-claim.sh`:
  - Args: `<goal-id> <nit-filename>`.
  - In `../void-slice-nits/`: `git fetch origin nits && git reset --hard origin/nits`, then `git rm kanban/nits/<file>`, `git commit -m "claim <file> for <goal-id>"`, `git push origin nits`.
  - On push failure, retry per CLAUDE.md exponential backoff (2s, 4s, 8s, 16s).
  - Exit codes: 0 win, 2 non-fast-forward (race lost), 3 network failure after retry, 1 any other error.
  - On exit 2: prints `claimed by another commit on origin/nits` to stderr.
- Materialized ticket format (literal, copyable):
  ```markdown
  # <goal-id>.<n> · <description from nit>

  **Status:** todo
  **Goal:** <goal-id>
  **Size:** small
  **Origin:** nit-<timestamp>

  ## What
  <captured prose from nit body — context paragraph if present, else just restate the description. Include `Originating branch: <branch>` line.>

  ## Scope
  - <captured Paths from nit file, repeated as concrete deliverables>

  ## Dependencies
  None.

  ## Verification
  <slicer fills this in during the disambiguation pass; if no clear verification can be named, the nit's adoption is reverted (manual `git -C ../void-slice-nits revert` of the claim commit) rather than shipping a ticket without a check>

  ## Out of scope (intentionally deferred)
  None.
  ```
- Numbering: adopted nits get `<n>` past the slicer's intentional tickets, counted via `ls kanban/{todo,in-progress}/<goal-id>.* 2>/dev/null | wc -l` after the slice's own tickets are written.

## Dependencies
M10.1, M10.2.

## Verification
- After `/nit` files a fitting nit, `/goal-slice <goal-id>` lets the user adopt it; a ticket file appears at `kanban/todo/<goal-id>.<n>-...md` with `**Origin:** nit-<timestamp>`.
- The claimed nit is gone from `origin/nits` (`git ls-tree origin/nits kanban/nits/<file>` empty).
- Concurrent claim simulation: invoke `tools/nit-claim.sh` from two terminals against a stale fetch of the same nit — one exits 0, one exits 2.
- Non-fitting nit (Paths not a subset): listed with ✗, not adopted unless user extends the goal's Paths and re-runs the overlap check (existing flow from M9, no new code).

## Out of scope (intentionally deferred)
- Auto-extension of goal's Paths to fit a non-fitting nit — must be a deliberate user step. Auto-extension would silently bypass M9's collision-avoidance contract.
- Claim revocation flow — if a goal abandons after claiming nits, the user manually re-files via `/nit`. Rare case; automation cost not justified.
- Auto-populated Verification field on materialized tickets — captured prose isn't structured enough to derive a check mechanically. Slicer fills it in or reverts the claim.
- Bulk-adopt-all without per-nit confirmation — explicit `pick subset` covers it; an `all` shortcut is fine but never silent.
