**Status:** todo
**Goal:** M8

## What

Resolve four structural footnotes that piled up across M8.1–M8.4. None of them block M8 from shipping; they cost attention every time someone reads the harness layout, and bundling them avoids four follow-up commits.

## Scope

What must end up true:

1. **Root npm root moved into `worker/harness/`.** Move root `package.json` and `package-lock.json` to `worker/harness/`. Update [Makefile](../../Makefile)'s `node_modules` and `worker-harness` / `oracle` targets to install + reference the new path (`npm --prefix worker/harness ci`; the `node` invocations don't need cwd change because Node walks up to find `node_modules/`). Update the `.gitignore` comment from "Node (worker harness — see worker/harness/)" to drop the parenthetical now that the manifest lives there. Verify `make worker-harness`, `make oracle`, `make harnesses` all still pass.

2. **CLAUDE.md `permissions` line aligned with reality.** [CLAUDE.md:55](../../CLAUDE.md#L55) currently lists "Pre-approved Bash: `go test`, `go build ./...`, `go vet ./...`, `grep`, `find`, `ls`. Still gated: `rm`, `git reset --hard`, `git push --force`, `git branch -D`." That allowlist no longer exists in [.claude/settings.json](../../.claude/settings.json) — `permissions.defaultMode` is now `bypassPermissions` (devcontainer is sandboxed). Replace the line with one that explains the actual mechanism: bypass-by-default in the devcontainer, with `permissions.deny` (currently empty) reserved for the genuinely destructive set.

3. **Shared wasm loader.** [worker/harness/harness.mjs:25](../../worker/harness/harness.mjs#L25), [worker/harness/worker-harness.mjs:50](../../worker/harness/worker-harness.mjs#L50), and [worker/harness/oracle.mjs:64](../../worker/harness/oracle.mjs#L64) each carry a near-identical `loadWasm()` (read `wasm_exec.js` shim, eval into globalThis, instantiate, microtask-wait, assert export). Extract into `worker/harness/wasm-loader.mjs` exporting one function; update the three callers. No behavior change; commit the rename and call-site swap as a single diff so it's easy to verify by inspection.

4. **`make harnesses` semantics clarified.** [Makefile:124](../../Makefile#L124) defines `harnesses: wasm-harness worker-harness web-harness` — it does not include `oracle`. A reader runs `make harnesses` expecting "all of them". Pick one: (a) rename `harnesses` → `layer-harnesses` and add `harnesses: layer-harnesses oracle` as the all-up alias, or (b) leave `harnesses` as-is and add `oracle` to the help text in a way that makes the boundary obvious. Decide during implementation, not now.

Out of scope: gitignoring `bin/` (`BIN_DIR=bin`, written by `make build`). Pre-existing footnote, predates M8 — file separately if it bites again.
