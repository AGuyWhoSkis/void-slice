# M12.12 · Generalize EOF anchor routing for non-`}` diagnostics

**Status:** todo
**Goal:** M12
**Size:** small
**Origin:** M12.6

## What

M12.6 closed a W=0 locality violation where `PARSE_EXPECTED_SEMICOLON`
fired at EOF on the `unterminated-brace` cascade fixture. The fix
introduced
[`cursor.lastConsumedEndSpan()`](../../internal/parse/parse.go) and
wired exactly one call site to it — the assignment-`;` emit in
`internal/parse/parse.go`. Every other EOF-emitting `diagSpan()` caller
still routes through `eofSpan()`:

- `internal/parse/parse.go:174` — `expectKind` (e.g. Version
  number-literal at EOF)
- `internal/parse/parse.go:199` — `expectSym` (general; used for `]`,
  `(` open, etc.)
- `internal/parse/parse.go:484` — `UNEXPECTED_TOKEN` "expected index
  value inside `[`"
- `internal/parse/parse.go:522` — `UNEXPECTED_TOKEN` "unexpected end
  of file in statement"
- `internal/parse/parse.go:625` — `UNEXPECTED_TOKEN` "expected value"
- `internal/parse/parse.go:653` — `UNEXPECTED_TOKEN` "unterminated
  tuple value"

For each, the right anchor depends on what's missing. Generally:
"missing block closer" wants the EOF/empty-line policy (M12.5); "missing
inline token" (terminator, value, index expr) wants the last-consumed-
token-end policy (M12.6's `lastConsumedEndSpan`). Today the choice is
implicit: anywhere `eofSpan` is the wrong policy, locality may break
under W=0 if a future mutator-shape surfaces that call site.

## Scope

- Per call site listed above, classify "block-closer vs inline-token"
  and route accordingly. Concretely: at each EOF emit site, replace
  `c.diagSpan()` with either `c.eofSpan()` (block-closer cases) or
  `c.lastConsumedEndSpan()` (inline-token cases).
- Keep `c.diagSpan()` for non-EOF paths — its non-EOF branch is the
  correct last-consumed-end anchor already.
- Add focused parser unit tests in
  [`internal/parse/parse_test.go`](../../internal/parse/parse_test.go)
  for each shifted call site: a minimal EOF-truncated input that
  exercises the path, asserting the diagnostic's `Span.Start` resolves
  to the expected `(line, col)`.

## Dependencies

M12.6 (closed — defines `lastConsumedEndSpan`).

## Verification

- `go test ./...` clean. `go test ./internal/harness/locality/...`

- New parser unit tests pin each rerouted call site.

## Out of scope

- Designing a span-policy interface that callers select declaratively
  (`expectSym(..., AnchorPolicyEOF)`). The current set is small enough
  to switch by call site; introduce an interface only if a future
  ticket adds more EOF anchor variants.
- Touching `closeObjectValue`'s `diagSpan().Start` wrap at line 709
  unless its anchor is shown to violate locality. Indirect use; out of
  this ticket's blast radius.
