# M9.6 · CI-feedback loop

**Status:** todo
**Goal:** M9
**Size:** medium

## What

Formalize the loop where an agent on a goal branch reads its PR's check status, fixes failing checks, and re-pushes — with no human in the inner loop. Today this works ad hoc when an agent happens to think to look; M9.6 makes it a first-class workflow so an agent picking up a goal mid-flight enters the loop without rediscovery.

## Scope

- Mechanism for the agent to consume PR check status (slash command, PR-activity subscription, or both — decided at implementation time)
- Loop terminates on green CI or on an explicit agent judgment that the failure is out of scope (which it surfaces to the human, not silently abandons)
- `CLAUDE.md` orients agents to the loop briefly — enough that a fresh session knows to enter it, not so much that it's reimplementing the logic in prose

## Dependencies

Soft on M9.3 (PRs exist on per-goal branches).

## Verification

An agent on a goal branch with a failing CI check reads the failure, fixes it, pushes, and reaches green without human intervention. A fresh agent session starting on the same goal mid-failure picks up and enters the loop without orientation from the human.
