# M6.1 · `wrangler.toml` cleanup

**Status:** done
**Goal:** M6
**Size:** small
**Blocks:** M6.2

## What

Collapse `wrangler.toml` to a single top-level config. Drop `[env.production]` and its duplicated `unsafe.bindings` block — they're a relic of the named-environment model M6 abandons in favor of Wrangler versions on a single script.

Verifiable by one no-behavior-change deploy to `main` after the change merges: production keeps serving from the `voidslice-api` script, with the same rate-limit binding and the same `ALLOWED_ORIGIN`.

## Scope

[wrangler.toml](../../wrangler.toml):
- Delete the `[env.production]` block.
- Delete the `[[env.production.unsafe.bindings]]` block.
- Keep top-level `[vars]`, `[observability]`, and `[[unsafe.bindings]]` exactly as today.
- Update the comment near `ALLOWED_ORIGIN = "*"` to note that custom-domain lockdown is deferred to M7.

[.github/workflows/ci.yml](../../.github/workflows/ci.yml):
- In the prod deploy step, change `command: deploy --env production` to plain `command: deploy`.

## Notes

The rate-limit binding (`namespace_id = "1001"`) will be shared across all preview versions once M6.2 lands. Acceptable at current traffic; flag in the commit message so a future reader isn't surprised.

## Dependencies

None.
