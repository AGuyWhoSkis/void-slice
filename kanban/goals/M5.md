The catch-all goal for tickets that improve how the team works rather than what ships. Claude Code harness (slash commands, hooks, subagents, allowlists), devcontainer, lint setup, kanban itself, test-corpus management. Different shape from M1–M4: ongoing, no defined finish line — a new ticket joins M5 whenever some piece of dev infra needs work.

**Scope:** `.claude/`, `.devcontainer/`, `Makefile`, `.github/workflows/`, the kanban tree itself, and test-fixture infrastructure under `testdata/`. Does **not** include linter or server source code — those belong to M1–M4.
