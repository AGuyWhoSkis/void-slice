# M13 — Whitespace-invariance as a hard property

The lexinvariance harness M12 stood up at [`internal/harness/lexinvariance/`](../../internal/harness/lexinvariance/) mutates inter-token gap bytes — collapse, reindent, tab/space — and compares the diagnostic-code multiset before vs. after. Today it reports findings; humans triage. The 2026-05-11 sweep produced six, each closed one at a time (M12.18 routed HLSL-flavored `.decl` files to a no-op handler; M12.16 fixed an indent-gated brace-count cascade; M12.17 fixed a component-close cascade). The motivating intuition is that *indentation should not affect structural diagnostics* — the grammar is not whitespace-sensitive, and every apparent counter-example so far has resolved to a cascade bug. M13 flips the posture: assert *whitespace in inter-token gaps does not change the diagnostic-code multiset* as a hard CI gate, then drive the sweep over [`testdata/golden/`](../../testdata/golden/) to zero. The work is two-pronged — flip the harness from report-only to fail-on-finding, and resolve every surviving finding by either fixing the engine or routing the file's class to a no-op handler at the linter's input boundary (M12.18 precedent). Reaching zero is likely to surface more cascade bugs of the M12.16/17 shape; that's the point — find them in one sweep rather than by inspection. Success: the harness fails CI on any inter-token-gap finding across [`testdata/golden/`](../../testdata/golden/), every M12-era finding is closed by fix-or-router, and from this goal's close forward any new finding must be closed by the same two mechanisms — **never by a per-file skip list**. The constraint is load-bearing: the web playground accepts pasted text without a filename, so path-based skips can't apply to the surface that actually serves users and would silently lie about coverage.

**Scope:** the lexinvariance harness's assertion shape (report-only → hard fail), the scanner/parser/validator fixes for every finding the post-M12 sweep produces, and any new file-class routers at the linter's input boundary needed to carve out non-grammar content (HLSL shader prefix being the canonical case from M12.18). Excludes token-level substitution as an invariance class — different substrate, parked as a future goal; newline mutation (`TransformBlankLine` and reindent's newline-injection paths stay in the harness but are not this goal's invariant); intra-token whitespace (part of the token, not the gap); cross-file reference resolution (the G-B candidate goal); and the cascade fixtures under [`testdata/cascades/`](../../testdata/cascades/), which are intentionally broken and governed by golden expectations elsewhere. Adjacent to [M12](M12.md), which built the harness substrate and set the file-class router precedent.
